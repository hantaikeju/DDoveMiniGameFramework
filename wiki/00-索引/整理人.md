# 整理人短号

Concept ID：`/00-索引/整理人`。

Agent **写/改业务篇之前**必须已经有生成人短号：本会话未问过就先问一次，再写 `generated.by: human:<短号>` 并挂到 `index_<短号>.md`。不要猜、不要用 `process:agent` 代替人。

业务目录用个人清单 `index_<短号>.md`（如 [`/02-程序-前/index_cjh`](/02-程序-前/index_cjh.md)），**不要** `index_1.md`。篇名仍按主题。谁整理写在**那一篇**的 frontmatter：

```yaml
generated: { by: human:cjh, at: 2026-08-31T03:00:00Z }   # 谁起草 / 谁整理
# verified: { by: human:cjh, at: 2026-08-31T03:00:00Z }  # 人确认后才写；有则算 human-reviewed
```

查某人整理过的篇：

```bash
rg -n "human:cjh" wiki/02-程序-前
```
