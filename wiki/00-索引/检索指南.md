# Wiki 检索指南

> Agent Skill：`mgf-wiki`。规范：仓库根 [`SPEC.md`](../../SPEC.md)，本库约定：[OKF约定.md](/00-索引/OKF约定.md)。

## 原则

1. 先读 [`/index.md`](/index.md) 或分类 `index.md`，再 Grep 概念正文。
2. 每个概念看 frontmatter：`type` / `tags` / `status` / `sources` / `verified`。
3. `type: Stub` 或 `wiki_stub: true` → 跟 `sources` 与文内 canonical，不当全文。
4. 无 `verified` 视为 unverified；与代码冲突以**当前代码**为准。
5. 刚替换 `SPEC.md`、或要合规巡检 / 升级 wiki：主动调用 `mgf-okf-upgrade`，不要在问答里升级。
6. 变更史先看 [`/log.md`](/log.md)（日期索引），再打开 `_log/log_YYYY-MM-DD.md`。`_log/` 不当概念检索。

## 命令

```bash
rg -n -g "*.md" "^type: |^title: |^tags: |关键词" wiki
rg -n "关键词" wiki/01-策划
rg -n "关键词" wiki/02-程序-前
rg -n "关键词" wiki/03-程序-后
rg -n "关键词" wiki/04-美术
```

检索根是仓库内 `wiki/`，不要用本机绝对盘符。
