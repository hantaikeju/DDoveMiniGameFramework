# 改工作区前缀

Concept ID：`/00-索引/Agent/改工作区前缀`。入口：[SKILL.md](../../../.agents/skills/ddove-rename-workspace/SKILL.md)。地图：[Agent 总览](/00-索引/Agent/Agent总览.md)。不是换引擎：换 `ddove-` 品牌走 [工作流迁移](/00-索引/Agent/工作流迁移.md)。

纯步骤，不写独立脚本。维护 skill 走 `ddove-writing-for-agents`。

## 要什么

别人 **fork / 拷走** 本仓开新游戏时用一次。用户给一个自定义名（如 `Foo`），拼出四件套并改仓库内指针。

| 旧 | 新 |
|----|----|
| `DDoveMiniGameClient/` | `{名}Client/` |
| `DDoveMiniGameConfig/` | `{名}Config/` |
| `DDoveMiniGameWiki/` | `{名}Wiki/` |
| `DDoveMiniGameTools/` | `{名}Tools/` |

根目录没有 `.sln`。Unity sln/csproj 随 Client 文件夹由编辑器重生，不要手改。

## 谁跑

只给 fork 开新游戏的人跑。**本框架仓不跑**（会拆掉模板身份）。

## 白名单（改）

先改四个顶层目录，再只改写死旧路径的指针：

- `gen_client.bat` / `gen_client.sh`（见 [DDoveCfg](/02-程序-前/DDoveCfg.md)）
- `AGENTS.md`、README
- `.agents/skills/` 与 `.cursor/skills/` 正文里的四件套路径
- wiki `sources`、约定篇、CI（`wiki-check.yml`）、`check_wiki.py`

改完：`{名}Wiki` 仍能被 `ddove-wiki` grep 到；`gen_client` 输出仍指向 `{名}Client`。

## 冻结（不改）

- `DDoveFramework`、现有 `ddove-*` 品牌名
- `Packages/`、`Library/`、`PackageCache`
- Unity PlayerSettings（`productName` / `companyName` / bundle）：用户自己在 Unity 里配
- 仓库根文件夹 `DDoveMiniGameFramework`、git remote

禁止全文盲搜 `DDoveMiniGame` 扫第三方包。

## 不要

- 当问答五段用（那是 `ddove-work`）
- 和 [工作流迁移](/00-索引/Agent/工作流迁移.md) 合成一个 skill
- 在本框架仓上试跑改名
- 手改 Client 下生成的 `.sln` / `.csproj`
