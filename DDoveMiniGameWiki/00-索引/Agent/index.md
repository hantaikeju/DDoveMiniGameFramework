# 概念

* [Agent 总览](Agent总览.md) - 两层 wiki 与全部 AI skill 地图。聊天里敲 `/ddove-help`。 `Reference`
* [需求稿工作流](需求稿工作流.md) - grill 对齐后落 draft 需求稿；过期篇走 update；处理完再 change-state。 `Playbook`
* [开篇与清单徽章](开篇与清单徽章.md) - 正文不自报 status；升 stable 摘需求 tag，只改清单那一行徽章。 `Playbook`
* [开工班组](开工班组.md) - ddove-work 按需求稿改代码时的计划 / 工人 / 调度 / 审查 / 评分。 `Playbook` `draft` `需求`
* [开工评分](开工评分.md) - 开工班组冻结的评分尺子。先分后改尺。 `Playbook` `draft`
* [show-me 安装](show-me安装.md) - 个人 skill 装到 `~\.cursor\skills\`，不进仓库 `ddove-`。 `Playbook`
* [工作流迁移](工作流迁移.md) - 换引擎只带走 AI 层与空工程壳。 `Playbook`
* [上游 skill 更新](上游skill更新.md) - 对照 mattpocock/skills 与 luban/ai 改编 `ddove-*`。 `Playbook`
