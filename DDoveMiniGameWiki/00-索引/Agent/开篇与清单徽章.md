# 开篇与清单徽章

Concept ID：`/00-索引/Agent/开篇与清单徽章`。接在 [需求稿工作流](/00-索引/Agent/需求稿工作流.md)，不另写第二份流程。地图：[Agent 总览](/00-索引/Agent/Agent总览.md)。维护 skill 走 `ddove-writing-for-agents`。

`status` 只乘 YAML。问答里点名 draft 不要抄进篇首。新建仍 `draft` 写完再升一次；不是 create 完就 change-state 再 update。

[DDoveAudio](/02-程序-前/DDoveAudio.md) 开篇仍写 draft，存量另走 `/ddove-wiki-update`。

## 要

- `ddove-wiki-create` / `ddove-wiki-update`：正文禁止写「本篇是 draft」「本文 `status: draft`」「不当发布依据」这类自报。阶段只看 frontmatter。
- `/ddove-wiki-change-state` 升 `stable`，且篇不在 `05-需求`：同步写 `verified`；**摘掉** `需求` tag。主题不再用这个字。
- 目标篇在 `05-需求`：这是整份需求做完。不把需求稿本身留成用法。按 `tags` 里的职种生成或改写用法篇：`策划` → `01-策划`；`程序-前` → `02-程序-前`；`程序-后` → `03-程序-后`；`美术` → `04-美术`；只有 `索引` + `agent` → `00-索引/Agent`。用法篇同一文件名，只写三块：干什么、有哪些接口、每个接口干什么。没有需求稿的「要什么 / 不要 / 验收」，没有 `## 评分`。`tags` 无 `需求`。`status: stable`，同步写 `verified`。目标目录已有同名篇则改正文并升 `stable`，不另开第二份。需求稿改为 `deprecated`，文件不删。正文留下 `## 要什么`、`## 不要`、`## 评分` 和用法篇链接；不留 `## 验收`、`## 落点`。`title` 仍含「需求稿」。得分留在需求稿。用法篇挂到目标目录的 `index_<短号>.md`；需求稿那一行徽章改为 `deprecated`。
- 同一刀只改**本篇所在清单那一行**末尾徽章（`index_<短号>.md`、本目录 `index.md`、`00-索引/index.md` 里挂了就改那行）：先 `type`；`status` 为 `draft` 或 `deprecated` 时再写对应词；`tags` 仍含 `需求` 则写 `需求`。升 `stable` 且已摘 `需求` 后只留 `type`。不重生成整份清单，不改根 `/index.md`。
- 改正文仍回 `draft`、摘 `verified`。再升正式另跑 change-state。不把两刀合成一条。

## 不要

- 开篇或结论段复述 YAML 的 `status`。
- change-state 改正文。例外：`05-需求` 整份做完时写用法篇三块，并把需求稿留下 `## 要什么`、`## 不要`、`## 评分` 和用法篇链接，不留 `## 验收`、`## 落点`。
- 扫全库徽章、重写整份 `index_*`。
- 错字 / 擦脏句可以一直留在 `stable`。
- 自动升 `stable`、第四种 `status`。
- 本稿验收清存量（Audio 开篇、已脏清单行）。

## 验收

1. 按 create / update 新建或改正文后，篇首没有 `status: draft` / 「本篇是 draft」/ 「不当发布依据」。
2. 篇不在 `05-需求`：change-state 升 `stable` 后该篇 `tags` 无 `需求`，清单那一行只留 `type`。篇在 `05-需求`：用法篇只写干什么 / 有哪些接口 / 每个接口干什么，`stable` + `verified`，`tags` 无 `需求`，无 `## 评分`，无「要什么 / 不要 / 验收」；需求稿为 `deprecated`，留下 `## 要什么`、`## 不要`、`## 评分` 和用法篇链接，不留 `## 验收`、`## 落点`，`title` 仍含「需求稿」，文件还在，该行徽章为 `deprecated`。
3. 同一次 change-state 不改其它行、不重写整份清单。
4. update 仍把 `status` 写回 `draft` 并删 `verified`；回复下一刀仍是 change-state。
5. 无第四种 `status`；无自动升正式。
6. 本篇再当约定：人跑 `/ddove-wiki-change-state` 升 `stable`。
